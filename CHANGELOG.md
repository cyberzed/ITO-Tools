# Changelog

What changed on the site, newest first. The site's **What's new** page is built from this file.

Versions follow `MAJOR.MINOR.PATCH`:

- **MINOR** for a new tool, page or feature. **PATCH** for a fix or a small wording change.
- **MAJOR** stays at 0 while the site is young.

Each version has a date and one or more of these sections: Added, Changed, Fixed, Removed.
Write each line for the people who use the site, not for developers.

## 0.2.0 - 2026-11-26

### Added
- Athlete cards: the Simulation page takes a random athlete through the snatch and the clean & jerk, attempt by attempt, with the 20 kg Rule and the total.
- In the Simulation the athlete can abstain from the rest of a lift or withdraw from the competition.
- An About page that says what the site is for, which rules it uses and who made it.
- A What's new page with the version number, and a New marker when the site has changed since your last visit.
- A Source on GitHub link in the bottom right corner.

### Changed
- The front page has an intro and lists every page of every tool.
- After a no lift the card strikes the weight through instead of circling it.

## 0.1.0 - 2026-11-25

### Added
- Weight classes: an overview of the senior men's and women's bodyweight classes.
- Weight classes: a training game where you pick the valid classes from a grid of 5 x 5 to 10 x 10 tiles, with Check answers and Reveal answers.
- Athlete cards: the initial card at weigh-in for a random athlete, with starting weights that respect the 20 kg Rule and a Reset button for a new athlete.
- Light and dark mode, following your system by default.
